# 현장 홍보물 기준 템플릿 (2026-11-19 대구 동일하이빌 확정 로직)
새 현장은 이 폴더 스크립트를 복사해서 사진 목록·문구만 바꿔 쓴다.
- prep.py: 사진 회전 보정, 뿌연 완성 사진만 대비·밝기 보정
- build_blog.py: 블로그 붙여넣기 페이지 (제목 "대구 욕실리모델링 | 단지명 욕실 N칸 규격 타일 시공", 이런 분께 도움 → 공정 → 완성 → Q&A 4개, 사진 25~30장, 3~4장마다 한 줄 설명)
- build_media.py: 인스타 15장(표지 → 공정 8 → 완성 5 → 마지막 장) + 블로그 대표이미지 A/B
- build_reel_short.py: 인스타 릴스 약 20초 (첫 화면 "욕실 N칸, N일" 숫자 훅, 공정 0.65초, 완성 1.1~1.6초, 사진 18장 내외)
- build_reel.py: 블로그용 긴 영상 약 26초 (blog_video.mp4)
- 올릴 때: media/<슬러그>/<버전>/ , blog/<슬러그>/<버전>/ 새 폴더 + version.json 갱신 (옛날 화면이면 자동으로 최신으로 다시 열림)
- 타일은 "대형 타일" 대신 규격(600각 등)으로, 시공 기간·동 이름은 사장님 확인값만
